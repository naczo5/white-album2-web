WHITE ALBUM 2 Extended Edition — Web Port & Browser Engine

Fan-made web port and visual novel engine for WHITE ALBUM 2 Extended Edition. Includes a browser reader with voice, BGM, and sound effect playback, calendar-annotated scene flowchart, walkthrough guide, CG/Music/Scene Extras gallery, and native PC save_XX.sav / Sys.sav save importer.

Source code and setup documentation are available on GitHub (naczo5/white-album2-web).
